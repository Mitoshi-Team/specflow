# Спецификация: Доменная модель (сущности)

## 1. Назначение

Описать ключевые доменные сущности пайплайна извлечения атрибутов: карточка товара, список атрибутов категории, извлечённое значение атрибута, нормализованное значение, результат извлечения, справочники и конфигурация порогов уверенности.

## 2. Глоссарий

- **Карточка товара (ProductCard)** — входные данные: заголовок (title), описание (description), структурированные атрибуты продавца (seller_attributes).
- **Атрибут (Attribute)** — характеристика товара (напр. `brand`, `model`, `color`, `storage`, `diagonal`, `battery_capacity`, `ram`, `drive`, `processor`).
- **Кандидат значения (AttributeCandidate)** — сырое извлечённое значение из текста с источником упоминания и оценкой уверенности.
- **Нормализованное значение (NormalizedValue)** — каноническая форма, приведённая к единому формату (единицы, синонимы, регистр), сопоставленная со справочником при необходимости.
- **Результат извлечения (ExtractionResult)** — структурированный набор (атрибут → нормализованное значение + уверенность) по карточке.
- **Справочник (Vocabulary/Mapping)** — множество допустимых канонических значений атрибута, маппинги синонимов/аббревиатур, правила нормализации.
- **Порог уверенности (ConfidenceThreshold)** — минимальное значение confidence, при котором значение считается достаточно надёжным для автоматического попадания в каталог.

## 3. Сущности

### 3.1 ProductCard (Входная карточка)

| Поле | Тип | Обязательность | Описание |
| --- | --- | --- | --- |
| product_id | string | Опционально | Идентификатор карточки (для сопоставления с эталоном/выходом). |
| title | string | Рекомендуемое | Название товара. |
| description | string | Рекомендуемое | Описание товара (свободный текст). |
| seller_attributes | dict[string, any] или list | Опционально | Структурированные поля продавца (ключ-значение). |
| category_id | string | Опционально | Идентификатор категории. |
| category_name | string | Опционально | Название категории. |
| language | string | Опционально | Язык текста (`ru`, `en`, `mixed`). |
| raw_text | string | Вычисляемый (опц.) | Конкатенированный текст для анализа. |

**Правило:** используется только текстовая часть. Изображения не входят в модель.

### 3.2 Attribute

| Поле | Тип | Обязательность | Описание |
| --- | --- | --- | --- |
| code | string | Обязательное | Уникальный код атрибута (snake_case). |
| name_ru | string | Обязательное | Человекочитаемое название на русском. |
| category_scope | string[] | Опционально | Список категорий, для которых атрибут применим. |
| is_required | boolean | Опционально | Является ли обязательным для категории. |
| value_type | enum | Обязательное | `string`, `number`, `enum`, `boolean`, `unit_value`. |
| unit | string | Опционально | Единица измерения по умолчанию. |
| allow_multiple | boolean | Опционально | Допускает несколько значений. |
| synonyms | string[] | Опционально | Синонимы/варианты написания. |
| vocab | string[] | Опционально | Допустимый список канонических значений (enum). |
| normalization_rules | object | Опционально | Правила нормализации. |

### 3.3 AttributeCandidate (Кандидат извлечения)

| Поле | Тип | Обязательность | Описание |
| --- | --- | --- | --- |
| attribute_code | string | Обязательное | Код атрибута. |
| raw_value | string | Обязательное | Значение как найдено в тексте. |
| normalized_value | string | Обязательное | Каноническое значение после нормализации. |
| confidence | float | Обязательное | Уверенность [0.0, 1.0]. |
| source_spans | Span[] | Опционально | Упоминания в исходном тексте (explainability). |
| evidence_text | string | Опционально | Фрагмент текста, подтверждающий значение (grounding). |
| extraction_method | enum | Обязательное | `rule`, `dict`, `ner`, `classifier`, `ml_transformer`, `llm`, `hybrid`. |
| is_confirmed_in_text | boolean | Обязательное | Подтверждено ли значение в исходном тексте (grounding). |
| features | object | Опционально | Доп. признаки при оценке. |

### 3.4 Span (Фрагмент источника)

| Поле | Тип | Обязательность | Описание |
| --- | --- | --- | --- |
| field | enum | Обязательное | `title`, `description`, `seller_attributes`. |
| start | int | Опционально | Начальная позиция (символы). |
| end | int | Опционально | Конечная позиция (символы). |
| text | string | Обязательное | Фрагмент текста с упоминанием. |

### 3.5 ExtractionResult (Результат по карточке)

| Поле | Тип | Обязательность | Описание |
| --- | --- | --- | --- |
| product_id | string | Опционально | ID карточки. |
| category_id | string | Опционально | ID категории. |
| category_name | string | Опционально | Название категории. |
| attributes | AttributeCandidate[] | Обязательное | Список извлечённых атрибутов. |
| status | enum | Обязательное | `ok`, `low_confidence`, `partial`, `error`, `skipped`. |
| low_confidence_count | int | Опционально | Кол-во атрибутов ниже порога. |
| needs_review | boolean | Обязательное | Требуется ли ручная проверка. |
| processing_time_ms | int | Опционально | Время обработки. |
| pipeline_version | string | Обязательное | Версия пайплайна. |

### 3.6 AttributeValue (Выходной формат для каталога/отчёта)

| Поле | Тип | Обязательность | Описание |
| --- | --- | --- | --- |
| attribute | string | Обязательное | Код атрибута. |
| value | string | Обязательное | Каноническое значение. |
| confidence | float | Обязательное | Уверенность [0.0,1.0]. |
| source | string | Опционально | Краткий источник (field + метод). |

### 3.7 PredictionRow (Формат файла предсказаний)

| Поле | Тип | Обязательность | Описание |
| --- | --- | --- | --- |
| product_id | string | Опционально | Идентификатор карточки. |
| title | string | Опционально | Исходное название. |
| category | string | Опционально | Категория. |
| [attribute_code] | string/float | Опционально | Значение по атрибуту (каноническое). |
| [attribute_code]_confidence | float | Опционально | Уверенность по атрибуту. |
| needs_review | boolean | Опционально | Флаг ручной проверки. |
| status | string | Опционально | Статус обработки. |

**Примечание:** для каждого извлечённого атрибута выводятся пара `value` и `confidence`.

### 3.8 Справочники и конфигурация

| Сущность | Поля | Назначение |
| --- | --- | --- |
| AttributeVocab | attribute_code, canonical_values[], synonyms_map{alias->canonical}, unit_mappings | Нормализация и валидация enum-значений. |
| UnitRule | attribute_code, from_units[], to_unit, convert_fn | Приведение единиц измерения. |
| BrandVocab | names[], aliases[], stopwords | Словарь брендов. |
| ConfidenceConfig | attribute_code (или default), threshold_auto, threshold_review, method_weights | Пороги и веса гибридного агрегирования. |
| CategorySchema | category, required_attributes[], optional_attributes[], schema_version | Схема обязательных/ключевых атрибутов по категории. |

## 4. Инварианты (правила домена)

- **Grounding**: `is_confirmed_in_text == true` для всех значений, попадающих в финальный `ExtractionResult`. Должно быть подтверждение хотя бы в одном `source_spans`.
- **Не выдумывать**: пайплайн не возвращает атрибут, отсутствующий в исходном тексте.
- **Канонизация обязательна**: `normalized_value` всегда в канонической форме. Для enum — только из словаря (либо помечается low_confidence при выходе).
- **Уверенность в [0,1]**: `confidence` нормализована. При агрегации используется взвешивание по `extraction_method`.
- **Единообразие по категории**: атрибуты извлекаются в рамках схемы категории.
- **Traceability**: результат хранит `source_spans`, `evidence_text` для воспроизводимости и ручной проверки.
- **Determinism по правилам**: rule-based ветки детерминированы. ML/LLM-вызовы фиксируются версией модели, промптом и параметрами для воспроизводимости.
