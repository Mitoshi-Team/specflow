# Спецификация: Продукт (бизнес-видение)

## 1. Что это

Сервис автоматического извлечения и нормализации характеристик товаров (Attribute Extractor) из полуструктурированных карточек продавцов для маркетплейса М.Видео.

**Ядро продукта (вход → выход):**
- **Вход:** текст карточки товара (название, описание, а также текстовые атрибуты продавца). Только текст — изображения не используются.
- **Выход:** структурированный JSON с выделенными атрибутами, где для каждого атрибута указаны каноническое значение и уверенность модели.

Решение преобразует название, описание и структурированные атрибуты продавца в единый набор канонических характеристик с оценкой уверенности модели.

## 2. Для кого

- **Каталог и контент-отделы М.Видео** — автоматизация наполнения карточек и снижение ручной разметки.
- **Команда поиска и фильтров** — повышение полноты и качества атрибутов для фильтров.
- **Продавцы (в перспективе)** — единообразное заполнение характеристик.
- **Аналитика и ассортимент** — корректное сопоставление товаров разных продавцов и принятие решений.

## 3. Проблема

Карточки продавцов заполнены неравномерно: важные характеристики часто в свободном тексте, записываются по-разному (синонимы, сокращения, разные единицы) или отсутствуют в структурированных полях. Это приводит к:

- Товар не попадает в фильтры поиска → покупатель его не находит.
- Нарушается сопоставление одинаковых товаров разных продавцов.
- Снижаются качество рекомендаций, персонализация, сравнение, ценообразование.
- В итоге снижается конверсия и GMV.

Сложности: огромная таксономия, длинный хвост редких значений (мало примеров), множественные варианты записи одного значения, постоянное появление новых товаров и категорий.

## 4. Цель

Снизить долю незаполненных характеристик и повысить качество нормализации при приемлемой стоимости инференса. Обеспечить контролируемую автоматизацию: только достоверные значения попадают в каталог, сомнительные направляются на ручную проверку.

## 5. Ценностное предложение

- **Повышение видимости товаров** — заполненные атрибуты выводят карточки в фильтры (позитивно влияет на CTR и конверсию).
- **Единообразие каталога** — приведение значений к каноническому виду и единым атрибутам внутри категории.
- **Контролируемое качество** — каждое значение сопровождается оценкой уверенности (human-in-the-loop).
- **Справедливость по категориям** — одинаково хорошо для массовых и редких категорий, для разных продавцов.
- **Гибридная экономичность** — дешёвые методы закрывают типовые случаи, дорогие (LLM) подключаются только при необходимости.
- **Устойчивость к изменениям** — работа с новыми категориями без полного переобучения (гибрид + ограничения схемой/справочниками).

## 6. Ключевые метрики (бизнес-ориентированные)

| Метрика | Целевое понимание | Приоритет |
| --- | --- | --- |
| Покрытие (Coverage) | Доля карточек, в которых обязательные атрибуты категории заполнены после автоматизации. | Критический |
| Качество с учётом трафика | Метрики (Precision/Recall/F1) взвешиваются по частоте использования фильтров по атрибуту. | Критический |
| Precision/Recall/F1 по каждому атрибуту | Точность и полнота извлечения, включая редкие значения (длинный хвост). | Критический |
| Доля отправляемых на ручную проверку | Доля предсказаний с уверенностью ниже порога. Баланс между покрытием и качеством. | Высокий |
| Стоимость обработки одной карточки | Условная стоимость инференса (правила/ML/LLM). | Высокий |
| Качество на редких категориях | Оценка по категориям на gold-сете (не усреднённая). | Высокий |
| Доля галлюцинаций (контроль выдумок) | Отсутствие извлечения атрибутов, не подтверждённых текстом карточки. | Критический |

## 7. Ограничения и принципы

- **Только текст**: на вход только заголовок, описание и атрибуты продавца. Изображения не используются.
- **Не выдумывать**: решение не должно генерировать характеристики, отсутствующие в тексте карточки. Обязательна проверка подтверждения в исходном тексте.
- **Канонизация**: каждое значение приводится к единому формату с учётом единиц измерения и синонимов.
- **Уверенность обязательна**: для каждого значения `confidence` [0.0,1.0]. Значения ниже порога не попадают автоматически без ручной проверки.
- **Гибридность**: правила/словари, NER/классификаторы, трансформеры, LLM — совместно (cascade cheap-first).
- **Работа со всеми категориями**: одинаковое качество для массовых и редких категорий.
- **Human-in-the-loop**: сомнительные случаи и ошибки возвращаются на ручную разметку и могут использоваться для улучшения.
- **Простота развёртывания**: контейнеры Docker (docker-compose), доступ через REST API.

## 8. Критерии успешности (бизнес)

1. Увеличение покрытия обязательных атрибутов ключевых категорий без потери Precision на эталоне.
2. Положительная динамика по метрикам с учётом трафика.
3. Стабильное качество на редких категориях (оценка по категориям на gold-сете).
4. Обоснованно выбранный порог уверенности, подтверждённый экспериментами.
5. Демонстрация управляемой стоимости (обоснование гибридного выбора vs. чисто LLM) в презентации.
